# THE CASH — метод від Content Papa

Статичний лендінг на GitHub Pages.

**Адреса:** https://vetalfilimonow.github.io/sait/

Джерело: HTML-віджет сайту vetalfilimonow.wixstudio.com/my-sitecash — вміст перенесено без змін.

## Структура
- `index.html` — уся сторінка: розмітка, стилі та скрипти в одному файлі
- `.nojekyll` — вимикає Jekyll, щоб HTML віддавався як є
- `img/` — фото автора та обкладинки бонусів

## Локальний запуск
```bash
python3 -m http.server 8000
```

## Фото
Посилання на картинки з Figma були тимчасовими й перестали працювати, тому:

- **Бонуси** — нові векторні обкладинки в стилі сайту: `img/oracle.svg`, `img/toolkit.svg`, `img/dividends.svg`.
- **Автор** — кадр із hero-відео, який Cloudinary віддає як JPG (середина ролика).
  Якщо кадр не сподобається, зміни `so_50p` на інший момент (`so_80p`, `so_3` — 3-тя секунда)
  або поклади своє фото в `img/` і впиши шлях.

Усі шляхи — у `CONFIG.images` в кінці `index.html`. Якщо файл не завантажився,
показується оформлена заглушка.
